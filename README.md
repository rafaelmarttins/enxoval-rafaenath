# ENXOVAL HOME

Crie um sistema completo de gerenciamento de enxoval de casamento como uma aplicação web interativa e funcional. O sistema deve incluir:

Funcionalidades Principais
Cadastro de Itens do Enxoval
Nome do item
Categoria (ex: cozinha, quarto, banheiro, sala, decoração, eletrodomésticos)
Quantidade desejada
Quantidade já adquirida
Valor unitário estimado
Prioridade (alta, média, baixa)
Status (não comprado, comprado, presenteado)
Loja/fornecedor (opcional)
Observações (opcional)
Visualização e Organização
Lista completa de todos os itens cadastrados
Filtros por categoria, status e prioridade
Busca por nome do item
Ordenação por diferentes critérios (nome, valor, prioridade, categoria)
Dashboard de Resumo
Total de itens cadastrados
Percentual de itens já adquiridos
Valor total estimado do enxoval
Valor já gasto
Valor restante a gastar
Gráficos visuais mostrando:
Progresso geral (% de itens comprados)
Distribuição por categoria
Distribuição de gastos
Edição e Exclusão
Permitir editar qualquer informação dos itens
Excluir itens da lista
Marcar itens como comprados ou presenteados
Armazenamento Persistente
Usar armazenamento local (localStorage ou similar) para salvar os dados entre sessões
Permitir exportar a lista (opcional)
Requisitos Técnicos
Criar como React Component (application/vnd.ant.react)
Design moderno e responsivo usando Tailwind CSS
Interface intuitiva e fácil de usar
Validação de formulários
Cores suaves e elegantes apropriadas para tema de casamento
Ícones usando lucide-react para melhor visual
Design e Experiência do Usuário
Layout limpo e organizado
Feedback visual para ações do usuário
Cards ou tabela bem formatada para exibir os itens
Formulário modal ou seção dedicada para adicionar/editar itens
Cores que transmitam alegria e organização (tons pastéis, dourado, rosa suave, etc.)
Mensagens de confirmação antes de excluir itens
Extras Desejáveis
Contador regressivo para a data do casamento
Opção de marcar itens como "presente de convidado" com nome do convidado
Avisos visuais para itens de alta prioridade ainda não adquiridos
Progresso visual por categoria
Crie uma aplicação totalmente funcional e pronta para uso imediato.
